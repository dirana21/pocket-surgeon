# 🦷 Кишеньковий хірург: Провідникові анестезії ЧЛД (ОНМедУ Edition)

> **Мобільний інтерактивний веб-тренажер та клінічна шпаргалка для студентів 3-го курсу стоматологічного факультету.**  
> Спеціально адаптовано під вимоги кафедри хірургічної стоматології Одеського національного медичного університету (ОНМедУ).

---

## 📱 Про додаток

На 3-му курсі хірургічної стоматології топографія провідникових анестезій — один із найвідповідальніших практичних заліків. Помилка в кілька міліметрів може призвести до потрапляння в крилоподібний м’яз (післяін'єкційний тризм) або паренхіму привушної слинної залози (парез лицевого нерва).

Цей додаток створений як зручний мобільний помічник, який працює прямо в браузері смартфона або як Telegram Web App (TWA).

---

## 🎯 Основні функції

### 1. 📖 Атлас 6 провідникових анестезій
- **Мандибулярна анестезія** (внутрішньоротовий аподактильний та пальпаторний спосіб за методикою ОНМедУ).
- **Торусальна анестезія (за Вейсбремом)** — одночасне вимкнення 3-х нервів (*n. alveolaris inferior, n. lingualis, n. buccalis*) без окремого вколу в щоку.
- **Туберальна анестезія** (горб верхньої щелепи, захист від поранення *plexus venosus pterygoideus*).
- **Інфраорбітальна (підочноямкова) анестезія** (пальпаторний контроль нижнього очноямкового краю).
- **Піднебінна анестезія** (*foramen palatinum majus*).
- **Різцева анестезія** (*foramen incisivum* та *papilla incisiva*).

### 2. 🎮 2D Інтерактивний Тренажер вколу
- **Інтерактивна схема ротової порожнини:** керування точкою вколу пальцем на екрані телефона.
- **Жива міліметрова телеметрія:** контроль висоти (+10 мм над оклюзійною поверхнею), зміщення в борозенку складки та кута шприца.
- **Симуляція ускладнень:** миттєве пояснення помилок (тризм при уколі в *m. pterygoideus medialis*, парез *n. facialis* при заглибленні >25 мм).
- **Аспіраційна проба:** анімація перевірки карпули на кров перед ін'єкцією.
- **Режим «Екзамен наосліп»:** вимкнення підказок та оцінювання точності за 5-бальною шкалою ОНМедУ!

### 3. 🦷 Зона сенсорної блокади (FDI формула)
- Інтерактивна зубна одонтограма: наочне підсвічування анестезованих зубів (від різців до молярів) для кожного квадранта.
- Опис зон вимкнення слизової оболонки, ясен, язика (*n. lingualis*) та підборіддя з губою (*n. mentalis*).

### 4. 🧪 Калькулятор карпул та адреналіну
- Слайдер ваги пацієнта (20–120 кг).
- Вибір анестетиків: **Артикаїн 4%** (Убістезин 1:200 000, Убістезин Форте 1:100 000, Септанест), **Мепівакаїн 3%** без вазоконстриктора, Лідокаїн 2%.
- Врахування коморбідностей: серцево-судинні захворювання, вагітність, тиреотоксикоз, алергія на сульфіти.
- Суворий кардіологічний ліміт: **0.04 мг адреналіну max** (не більше 2 карпул 1:100 000!).
- Наочний графічний ряд ампул (карпул) із кольоровою шкалою безпеки.

### 5. 📋 Ситуаційні задачі та шпора з невідкладних станів
- Реалістичні тести кафедри хірургічної стоматології з детальним поясненням логіки кожного варіанта.
- Алгоритм дій при вазовагальному колапсі, адреналіновій реакції та анафілаксії.

## 🚀 Як опублікувати на GitHub Pages

### Спосіб 1: Автоматично через GitHub Actions (Рекомендовано)
1. Створіть новий репозиторій на [GitHub](https://github.com).
2. Запушіть код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Pocket Surgeon app"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЮЗЕРНЕЙМ>/<НАЗВА_РЕПОЗИТОРІЮ>.git
   git push -u origin main
   ```
3. У репозиторії перейдіть у **Settings** $\rightarrow$ **Pages**.
4. У пункті **Build and deployment** $\rightarrow$ **Source** виберіть **GitHub Actions**.
5. Проєкт автоматично збілдиться і опублікується за адресою:  
   `https://<ВАШ_ЮЗЕРНЕЙМ>.github.io/<НАЗВА_РЕПОЗИТОРІЮ>/`

### Спосіб 2: Локальний запуск
```bash
npm install
npm run dev
```
